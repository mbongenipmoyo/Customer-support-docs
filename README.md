Remote Operations Team Leader (13 handlers, Victoria Falls International Airport) transitioning to Remote Customer Support & Billing Support.

## What this repo is for
This is my playbook for accurate, async customer support - the same discipline I use for aircraft turnarounds.

### 1. Billing Support FAQ Template
- How to verify invoice, payment status, credit usage
- Steps: Reproduce issue -> Check Stripe/billing logs -> Document -> Escalate to Billing Engineering with clear repro steps
- Empathy script: Acknowledge, explain in plain English, confirm resolution

### 2. Escalation SOP
- L1: Email/chat support - gather account ID, invoice ID, screenshots
- L2: Billing Ops - manual billing processes, enterprise/HIPAA contracts
- L3: Engineering - include logs, timestamps, EMEA timezone

### 3. Shift Handover Log (from ramp to support)
- Date, open tickets, pending billing queries, blockers, next shift actions
- Used to run async team of 13 across day/night shifts - no meeting needed

### 4. Async Communication Rules I Use
- Write everything down - next person shouldn't need to call
- Urgent = call, non-urgent = ticket/log
- 4h overlap with EMEA/SAST, clear ownership
